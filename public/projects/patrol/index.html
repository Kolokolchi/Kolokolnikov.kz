Patrol Control

Бортовой интерфейс для света, оборудования и телеметрии.

ФорматПриложение
СтатусЛокальный прототип
В проектеПриложение / React / ESP32

Локальный прототип, офлайн-режим. Показатели на экране не являются измерениями подключённого автомобиля.

О проекте

Приложение для управления дополнительным оборудованием внедорожника. В интерфейсе собраны освещение, датчики, карта и диагностика. В презентации показан локальный интерфейс без подключения к автомобилю.

Что внутри

  • Единая панель управления оборудованием
  • Управление дополнительным светом
  • Экраны датчиков и диагностики
  • Интерфейс для телефона и бортового экрана
